# Pokémon GO AssetBundles

A repository containing **AssetBundles from Pokémon GO**.

## Unity Version

The AssetBundles in this repository were built with:

```text
Unity 6000.3.21f1
```

Using the same Unity version is recommended when inspecting or researching these AssetBundles, as Unity AssetBundles can be sensitive to the version and build pipeline used to create them.

## About Pokémon GO

**Pokémon GO** is a mobile game based on the Pokémon franchise.

The game was originally developed and operated by **Niantic** following its launch in 2016. In 2025, **Scopely acquired Niantic's games business**, which included Pokémon GO. The transaction closed on **May 29, 2025**.

The Pokémon GO development team joined Scopely as part of the acquisition. Scopely currently describes the Pokémon GO team as part of **Scopely Explore** and states that these games are developed and published by Scopely.

## Opening the AssetBundles

The recommended tool for inspecting these AssetBundles is **AssetStudioMod**:

[AssetStudioMod — GitHub](https://github.com/aelurum/AssetStudioMod?utm_source=chatgpt.com)

AssetStudioMod is a modified version of AssetStudio with additional functionality and UI improvements. It supports loading Unity AssetBundles directly.

### Basic Usage

1. Download and install/run AssetStudioMod.
2. Open **File → Load file** to load an individual AssetBundle.
3. Alternatively, use **File → Load folder** to load a directory containing multiple bundles.
4. Browse the assets in the **Asset List**.
5. Use the **Export** menu to export supported assets.

AssetStudioMod can export various Unity asset types, including textures, sprites, audio, meshes, fonts, animations, and other supported assets.

### Unity Version Compatibility

These AssetBundles were built with:

```text
Unity 6000.3.21f1
```

AssetStudioMod's current documentation lists Unity support through `6000.2`, so **Unity 6000.3.21f1 is newer than the version explicitly listed as supported**. Some assets may therefore fail to load or decode correctly.

If an AssetBundle does not open correctly, it may be due to changes between Unity versions rather than a corrupted file.
